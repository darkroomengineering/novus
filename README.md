# Novus

**Novus** — Latin for "new" — a modern, full-stack React application that embodies fresh beginnings.

Built with React Router, Sanity CMS, and cutting-edge tooling for a seamless development experience.

## Key Dependencies

- **React Router** - Full-stack React framework
- **Sanity** - Headless CMS with visual editing
- **Tailwind CSS** - Utility-first styling
- **Motion** - Animation library
- **TypeScript** - Type safety
- **Biome** - Fast linter and formatter
- **Vite** - Build tooling

## Getting Started

```bash
bun install
bun dev
```

Visit `http://localhost:5173` to see your application.
